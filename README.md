# 🧁 Sweets Delights Website

O Sweets Delights é um site para uma doceria, desenvolvido utilizando apenas HTML e CSS. O layout é simples e intuitivo, projetado para apresentar os produtos e informações da doceria de forma clara e acessível. O site contém quatro seções principais: Home, Catálogo, Loja e Contato, cada uma com uma tela dedicada.


 ## ⚙️ Estrutura do Site
 
1. Home
Exibe informações gerais sobre os produtos oferecidos pela doceria, destacando a qualidade e variedade dos doces e bolos.
Inclui imagens localizadas na pasta Foto-Home para enriquecer a apresentação visual.

2. Catálogo
Apresenta duas opções de catálogos:
Catálogo de Bolos: Ao clicar, abre um arquivo PDF com o catálogo de bolos.
Catálogo de Doces: Ao clicar, abre um arquivo PDF com o catálogo de doces.

Os PDFs estão localizados na pasta Catalogo.

3. Loja
Contém informações sobre a localização da doceria:
Integração com o Google Maps para exibir o local exato da loja.
Endereço completo da doceria, incluindo número de telefone para contato.

4. Contato
Fornece as opções de contato com a doceria:
Telefone: Número para ligações diretas.
WhatsApp: Link ou número para contato via WhatsApp.
E-mail: Endereço de e-mail para comunicação.


## 🔧 Tecnologias Utilizadas

HTML: Estruturação do conteúdo das páginas.
CSS: Estilização do layout, com o arquivo Style.css na raiz do projeto, garantindo um design responsivo e visualmente atraente.

 ## 📂 Estrutura de Arquivos
 ```bash
Site_Sweets_Delights/
├── Catalogo/             # Arquivo index, style e imagens ultilizadas na tela Catálogo
├── Contato/             # Arquivo index, style e imagens ultilizadas na tela Contato
├── Foto-Home/             # Arquivo com as imagens ultilizadas na tela Home
├── Loja/             # Arquivo index, style e imagens ultilizadas na tela Loja
├── Style.css              # Arquivo de estilização da pagina inicial
└── Index.html             # Página principal (Home)
```

## 🚀 Como Executar

```bash
Clone o repositório ou baixe os arquivos do projeto:git clone <URL_DO_REPOSITORIO>
```

Abra o arquivo Index.html em um navegador web para visualizar o site.
Certifique-se de que os arquivos PDF na pasta Catalogo estão corretamente vinculados no HTML.
Verifique se as imagens na pasta Foto-Home estão referenciadas corretamente no Index.html.
Para a seção de Loja, confirme que o link do Google Maps está configurado com as coordenadas corretas.

## 📌 Observações

O site foi projetado para ser simples e funcional, utilizando apenas HTML e CSS, sem dependências de frameworks ou bibliotecas externas.
Certifique-se de que os arquivos PDF e imagens estejam acessíveis e que os links de contato (telefone, WhatsApp e e-mail) estejam corretamente configurados no arquivo contato.html.
